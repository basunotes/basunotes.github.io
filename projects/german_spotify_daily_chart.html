German Spotify Daily Chart

I wanted to have a simple way of seeing what is currently popular on Spotify in Germany, so I built a small data pipeline around the German Daily Top 200. The pipeline downloads the daily chart, enriches the tracks with Spotify metadata, stores the historical data in MySQL, and displays the results in an interactive Streamlit dashboard. The application runs in Docker on an AWS EC2 instance and is deployed automatically through GitHub Actions.

Link to dashboard

The dashboard is served over HTTP, so your browser may show a security warning. This warning is harmless here, as the dashboard does not collect any sensitive or personal data.
