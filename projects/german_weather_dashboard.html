(Berlin) Weather Dashboard

I wanted to build a simple weather dashboard that shows the current weather in Berlin together with an hourly and multi-day forecast. The application retrieves weather data from Bright Sky, which provides weather information based on data from the German Weather Service (DWD). The backend is written in Python with Flask and processes the raw weather data into current conditions, hourly forecasts, an 8-day forecast, and chart data for temperature, precipitation probability, and wind speed.

The frontend is built with HTML, CSS, and JavaScript and updates dynamically through a Flask API. Weather data is cached to reduce unnecessary API requests, and previously cached data can be used as a fallback if the external weather service is temporarily unavailable.

The application runs in Docker on an AWS EC2 instance, with Gunicorn serving the Flask application and Nginx acting as a reverse proxy. The source code is stored in a private GitHub repository, and changes pushed to the main branch are deployed automatically to EC2 through GitHub Actions using a self-hosted runner.
